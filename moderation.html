🎪 Gestion des Events

Les events peuvent être sélectionnés comme source d'obtention dans le Creator. Exemple : "Noël 2025".

🌍 Gestion des Worldboss

Un emoji par world boss, affiché devant son nom dans le menu du Compendium. Les world boss sont les mobs de type « WorldBoss » (créés dans le Creator). Champ vide = ☠️.

🔮 Forgerons d'items secrets

Tant que le secret est actif, ces PNJ (type « Forgeron d'items secrets » ou tag fabricant secret) n'apparaissent ni sur la carte ni dans le bestiaire, et l'obtention de leurs items affiche « Forgeron d'items secret - Position cachée pour l'instant ». Leurs items restent visibles dans le Compendium et l'Atelier.

📣 Envoi Discord des nouveaux items

Les chefs de serveur configurent le bot eux-mêmes sur la page d'inscription. Ici tu vois l'état de chaque serveur (« 👁 Choix », « 📜 Historique », progression) et tu peux agir à leur place avec « 🛠 Gérer ». Rien n'est envoyé avant ta validation.

🏰 Gestion des Donjons

Les donjons créés ici apparaissent dans la source d'obtention « Donjon » du Creator, avec un pourcentage d'obtention. Exemple : "Crypte Oubliée".

🏅 Gestion des Titres

Les titres créés ici apparaissent dans le menu « Titre » de l'Atelier. Chaque titre ajoute ses stats au build (par exemple +5 Santé). Exemple : "Tueur de Dragons".
